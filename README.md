# NYC Yellow Taxi Demand & Revenue Analytics

An end-to-end data analytics project exploring New York City's Yellow Taxi operations using Python, DuckDB, SQL, statistical analysis, and Power BI.

## Project Overview

This project analyzes January 2025 NYC Yellow Taxi trip records to identify demand patterns, geographic concentrations, popular routes, and passenger charge trends.

## Business Objectives

- Identify peak taxi demand periods.
- Analyze the busiest pickup and drop-off zones.
- Identify the most frequently travelled zone pairs.
- Compare weekday and weekend demand.
- Examine fare, distance, and trip-duration patterns.
- Present findings through an interactive Power BI dashboard.

## Technology Stack

- Python
- Pandas and NumPy
- DuckDB and SQL
- GeoPandas
- Power BI and DAX
- Excel

## Dataset

Source: NYC Taxi & Limousine Commission.

Period: January 2025.

Dataset: Yellow Taxi Trip Records.

[Official TLC Data Source](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)

## Project Workflow

1. Data exploration and validation.
2. Data cleaning using Python and DuckDB.
3. SQL-based aggregation and analysis.
4. Geographic coordinate preparation using GeoPandas.
5. Statistical analysis of demand patterns.
6. Power BI dashboard development.

## Power BI Dashboard

The dashboard contains three analytical pages:

1. Executive Overview
2. Geographic Demand Analysis
3. Demand Patterns and Statistical Insights

## Repository Contents

- Jupyter Notebook: Python analysis and data processing.
- SQL: Analytical queries.
- Excel: Processed datasets.
- Power BI: Interactive dashboard.
- Reports: Statistical findings and conclusions.

## Data Limitations

- The analysis covers one month only.
- Geographic coordinates represent taxi-zone centroids, not exact pickup GPS coordinates.
- Zone-to-zone connections do not represent actual road paths.
- Passenger charges are not equivalent to company profit or driver earnings.
